Mockup · Categories

Categories don't scale past a dozen

Both the Add transaction picker and the Profile → Categories tab draw every category at once. With 16 that is a long block; with the allowed 50 the picker pushes Description and Date off screen, and Profile becomes a wall of tiles with the editor opening far below. This page uses a realistic set of 50 categories so the problem shows at full size.

High severity Medium Search in every mockup works and ignores accents: try an trua, tra sua, hieu

01Today

Rebuilt in HTML from the 8 Nov screenshots, but filled with 50 categories instead of 16.

  1. The picker grows with every category HighThe 3-column grid renders all of them (QuickEntryParts.tsx:101). 50 categories = 17 rows ≈ 750px before Description, Date and Repeat.
  2. Order is creation order, not use HighCategories show in the order they were added. The default is always the first one ever created (quickEntry.ts:80), so Breakfast is selected at 9 pm.
  3. Search misses Vietnamese names MediumIt only lowercases, so an trua does not match "Ăn trưa", and Enter does not pick the first match. It only appears above 8 categories.
  4. The phone dock has no search at all HighCategoryChips (QuickEntryParts.tsx:88) is one sideways row: 50 chips means a long swipe.
  5. New categories all look the same MediumEach new one starts as a green $ (UserProfile.tsx:192); there are only 12 icons and 9 swatches. Your "1"–"5" are indistinguishable without reading.
  6. Profile editor opens far from the tile MediumThe form sits after the whole grid (UserProfile.tsx:445).
  7. No way to find dead categories MediumNo use counts or last-used date, and at the 50 cap an unused category blocks a new one.
  8. Removed categories may show an ID To verifyRemove deletes the category; the display falls back to the raw id (MobileUi.tsx:18), likely a UUID on past spendings.

02Who and when

Daily logger

As someone who logs breakfast, lunch and coffee every day, I want my usual categories one tap away so that adding a spending takes under 5 seconds.

Detailed tracker

As someone with 40+ categories, I want to type two letters and press Enter so that I never scroll a grid.

Bilingual user

As someone who names categories in Vietnamese, I want search to work without typing accents so that I can use a plain keyboard.

Tidier

As someone near the 50 limit, I want to see what I never use so that I can archive it without losing old spendings.

04Recommendation

Build A for the picker (desktop dialog and phone dock share it) and D for Profile, with E's "next unused color and icon" for new categories. Leave groups (C) for later; they need a data change and A already solves the length problem. Verify issue 8 first: if removed categories really show an id, switch Remove to Archive in the same change.

v1 Bad Practice · P0 WeekView Punishes Normal Spending in Red WeekView.css:96,124,244 painted normal daily dots, weekly spent totals, and every single transaction row in --danger (#ef4444), causing alarm fatigue.
v2 Fixed · P0 Neutral --money-spent for Normal Expenses Normal transactions and weekly spent totals render in calm --money-spent; --money-over amber is reserved strictly for over-budget items and --danger for destructive actions.
v1 Bad Practice · P0 Token Drift + Neon Purple + Green Expense Server defaults seeded Food: #10b981 (income green) clashing with --cat-Food: #f43f5e, while Analytics used neon purple --accent: #a78bfa and #6366f1 indigo.
v2 Fixed · P0 0 Category Divergences & Calm Jade-Teal Accent Category defaults match --cat-* 1:1 (green strictly reserved for income/left), and --accent is muted to jade-teal (#5eb8a0 dark / #2b605c light).
v1 Bad Practice · P1 Faux-Bold Weights, Missing .money & Clipped <select> Carets CSS requested unimported weights 750/800/900, omitted tabular-nums on KPI/Donut/Form amounts, mixed 5 primitive dialects, and left native <select> arrows pinned flush against the right border.
v2 Fixed · P1 Unified .money, .ui-* Layer & Inset <select> Chevrons Added .money-hero/.money-row/.money-sm (weight 500–600, tabular-nums, 0.65em ₫), capped weights at 700, added .ui-* primitives, and normalized all <select> controls with appearance: none + inset SVG chevron (right 10px).
v1 Bad Practice · P2 Buried Answers, Dense Charts & Missing Trust Controls Daily allowance was tiny subtext, Pace was prose, no 7-day bill strip existed, Donut had 6+ slices beside Pareto/PunchCard grids, and Privacy Blur / 1-Tap Export / Family Paid by were absent.
v2 Fixed · P2 Clear Daily Answer, Calm Charts & Family Trust Added topbar Privacy Blur, elevated Safe to spend today + visual Pace bar + Next 7 Days strip, capped Donut at 5 series + Other, collapsed statistical charts, and added CSV/JSON Export + Paid by pills.

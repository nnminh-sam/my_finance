Analytics SVG Chart Library (src/components/charts.tsx)

9 SVG chart exports rendered with CSS variables and computeMonthlyAnalytics() data. Five are responsive via ResizeObserver (useContainerWidth: Cumulative, Daily, Weekday, Pareto, Trend). Donut, PunchCard, ProgressRing and Sparkline are fixed-size.

7 core · 2 statistical

Current state (checked against src/)

Read before the specimens

App order: KPI row (ProgressRing, Sparkline) is the first row of the grid, then Cumulative, Donut, Daily, Weekday, PunchCard, Pareto, Trend. Mobile analytics reuses only CumulativeChart (MobileAnalytics.tsx:127); its .m-bars, .m-heat, .m-cols and .m-legend are not charts.tsx exports and are not shown here.

Number formatting (current, not yet one rule):

  • Axes, bar and point labels, donut centre, and the analytics hero caption: fmtCompact, no unit, e.g. 10M.
  • Tooltips and full KPI values (AnalyticsView.tsx): fmtVND, e.g. 1.234.567 ₫.
  • Mobile KPIs (MobileAnalytics.tsx:113-115): fmtCompact with a ₫ suffix, e.g. 1.2M ₫.

Known issues in the app (APP-DEFERRED, not fixed in the showcase):

  • Audit F-01: chart SVGs in charts.tsx have no role or accessible name. The specimens below carry role="img" and labels, which the app does not yet.
  • Audit F-03: formatting above differs by surface. The rule is not unified yet.
  • Audit F-08: the donut fallback palette is raw hex (FALLBACK_COLORS, AnalyticsView.tsx:49). The donut specimens use the same hex, not tokens.
  • Audit F-09: interaction is hover-only (onMouseEnter/onMouseMove), with no keyboard, focus or touch path. The specimens show hover and selected states; the app has no focus state.

Empty & degenerate states

Documented from src; the app has no loading state

No spending data for June 2026

Add some expenses and your analytics will appear here.

  • Sparkline: fewer than 2 values returns null (renders nothing).
  • ParetoChart: renders nothing with 1 or fewer points, or before the container is measured.
  • ProgressRing: value is clamped to 0–1, so a negative savings rate draws an empty ring. With no income set the centre shows “—” in --text-muted; negative rates use --danger.
  • All charts render nothing until the container width is measured (width > 0). There is no loading state.
